For solids of revolution (constant radius per axial station). Meshes a radial profile and revolves it into a structured hex mesh. Refuses non-axisymmetric geometry.

Hex-dominant uses Gmsh's HXT mesher; if it can't mesh the geometry it falls back to tetrahedral.

Pick a source face and a target face (parallel/opposite). The source is meshed and swept to the target.
